# Freight Hub for Outlook

These are the files for the Freight Hub panel in new Outlook. They go in a public GitHub repository with GitHub Pages turned on: `taskpane.html`, `taskpane.css`, `taskpane.js` and the `assets` icons. The panel shows the load for the email you have open and saves it to the load when you tap Save. It talks only to the Freight Hub Outlook API address and your key, and you type both into the panel once. Outlook keeps them in your mailbox settings. `manifest.template.xml` is filled in by the Hub (More › Outlook › Download manifest). `Outlook API.gs` is the code for the small "Freight Hub Outlook API" Apps Script project, not for GitHub.

**No keys or data belong in this folder.**
